# Build a dual-campaign first playable slice

Status: Accepted

The next major milestone is a First Playable Slice in both Ages and Seasons rather than an immediate attempt to make either full campaign completable. Each slice must connect authentic movement and animation, collision and transitions, an NPC interaction with dialogue, an enemy and defeat flow, the sword and one secondary item, a persistent pickup or chest, a minimal HUD, save/reload, music, and representative sound effects. This exercises the shared runtime end to end before object-family breadth and full progression multiply the debugging surface.
