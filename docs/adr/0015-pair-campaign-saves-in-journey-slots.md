# Pair campaign saves in Journey Slots

Status: Accepted

The Oracle Redux shell exposes three Journey Slots, each pairing independent Ages and Seasons campaign records under the original linkage identity, names, and linked-game state. Completing one campaign may start the other directly as a Linked Journey, while original transfer secrets remain accepted and generated. Import maps a selected cartridge slot into the corresponding campaign half, and each half remains independently exportable as a compatible Original Save Image.
