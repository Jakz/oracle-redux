# Use an orthographic 2.5D visual model

Status: Accepted

Oracle Redux presents original ROM-derived pixel art in an orthographic 2.5D world with explicit visual layers, height, depth ordering, and shadows. Lighting, fog, selective depth blur, grading, and related effects may use that visual depth, but the baseline does not require perspective cameras, 3D meshes, or replacement artwork. This preserves the campaigns' pixel identity while providing the spatial information required for the ProjectZ-inspired modern presentation.
