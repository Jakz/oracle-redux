# Defer trace verification until after the first playable runtime

Status: Accepted

Oracle Redux prioritizes reaching a playable Native Behavioral Reimplementation before building the original-versus-C++ trace harness. During this phase, gameplay may advance as Provisional Behavior when it is grounded in disassembly evidence and covered by ordinary tests. Trace verification remains a deferred release gate: provisional systems must be covered retroactively before either campaign is described as fidelity-complete.
