# Ship authored presentation metadata

Status: Accepted

Oracle Redux ships engine-owned Presentation Metadata keyed by stable campaign, tileset, metatile, and object identifiers. These annotations may define visual height, sorting layers, overhead occlusion, shadows, materials, focus participation, and lighting parameters needed by the 2.5D World Presentation. They contain no extracted campaign pixels, text, audio, maps, or other original content; the player's ROM Source remains authoritative for those assets.
