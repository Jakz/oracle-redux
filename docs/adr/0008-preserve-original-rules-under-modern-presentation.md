# Preserve original rules under modern presentation

Status: Accepted

The default Modern Profile changes presentation, not authoritative gameplay: widescreen composition, continuous scenery, interpolation, scalable interface, lighting, depth effects, and shaders remain compatible with the Fidelity Baseline. Gameplay Extensions such as activating enemies and scripts across multiple rooms, seamless cross-room combat, expanded item actions, or balance changes are separate explicit opt-ins and are not enabled merely because neighboring rooms are visible. This prevents visual modernization from silently changing campaign outcomes and amends the gameplay-changing Modern defaults described by ADR-0003.
