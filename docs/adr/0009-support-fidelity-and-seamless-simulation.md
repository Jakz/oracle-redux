# Support fidelity and seamless simulation

Status: Accepted

Oracle Redux supports both Fidelity Activation and an opt-in Seamless Simulation Extension. Fidelity Activation reproduces the original room-defined update boundary; seamless simulation advances a deterministic multi-room world-space region around Link. Neither mode derives authoritative activation from the Presentation Camera, so window size, aspect ratio, and zoom cannot change gameplay outcomes. This retains the broader-world option inspired by ProjectZ without compromising the default Fidelity Baseline.
